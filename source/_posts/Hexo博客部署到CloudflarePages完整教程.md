================================================================================
                Hexo 博客部署到 Cloudflare Pages 完整笔记（全量版）
================================================================================

目标：本地写 Markdown → 推到 GitHub → Cloudflare Pages 自动构建 → 用 readhaven567.top 访问
作者环境：Windows 11 / Node.js v24.15.0 / Git / GitHub / Cloudflare / GoDaddy
最后更新：2026-10-13
博客地址：https://readhaven567.top
GitHub 仓库：https://github.com/suvenG123/hexo-blog


================================================================================
一、需要的软件和账号
================================================================================

软件 / 平台          作用                      下载地址
--------------------------------------------------------------------------------
Node.js（LTS）       运行 Hexo                 https://nodejs.org
Git                  推送代码到 GitHub          https://git-scm.com
Hexo-CLI             生成博客框架              npm 安装
GitHub               存放博客源码              https://github.com

GoDaddy              域名注册商（只改 NS）      —

      走的是「Cloudflare Pages 拉 GitHub 源码自动构建」。


================================================================================
二、本地安装 Node.js 和 Git
================================================================================

1. 安装 Node.js
   - 去 nodejs.org 下载 LTS 版本（v24.15.0）
   - 一路下一步安装
   - 安装完打开终端验证：
       node -v
       npm -v
     能看到版本号 = 成功

2. 安装 Git
   - 去 git-scm.com 下载
   - 安装时默认选项即可
   - 验证：
       git --version

3. 配置 Git 用户名（第一次必做）
       git config --global user.name "你的GitHub用户名"
       git config --global user.email "你的GitHub邮箱"


================================================================================
三、安装 Hexo 并初始化博客
================================================================================

1. 全局安装 Hexo-CLI
       npm install -g hexo-cli
   验证：hexo -v

2. 新建博客目录
       D:
       mkdir hexo-blog
       cd hexo-blog

3. 初始化 Hexo
       hexo init
       npm install

4. 本地预览
       hexo clean
       hexo generate
       hexo server
   浏览器打开 http://localhost:4000


================================================================================
四、写文章
================================================================================

方式一：命令行新建（推荐）
       hexo new "文章标题"
   生成位置：source/_posts/文章标题.md

方式二：手动放文件
   直接把写好的 .md 文件放进 source/_posts/ 文件夹。

⚠️ 文章格式注意事项（非常重要！）
   每篇文章最顶部必须有 Front-matter 头信息，否则 Hexo 会报错（js-yaml 报错）并跳过渲染：

   ---
   title: 文章标题
   date: 2026-10-13 10:00:00
   tags: [标签1, 标签2]
   categories: 分类名
   ---

   正文内容写在这里...

   常见格式错误：
   - title: 后面没打空格（正确：title: 标题，错误：title:标题）
   - 少了开头或结尾的 ---
   - 日期格式不对
   - 文件名带 .md.md 双后缀


================================================================================
五、创建 GitHub 仓库
================================================================================

1. 登录 GitHub → New repository
2. 仓库名：hexo-blog
3. 选 Public
4. 不要勾 Add README
5. 点 Create repository


================================================================================
六、推送代码到 GitHub
================================================================================

方式一：命令行
       cd D:\hexo-blog
       git init
       git add .
       git commit -m "初始化Hexo博客"
       git branch -M main
       git remote add origin https://github.com/suvenG123/hexo-blog.git
       git push -u origin main

方式二：GitHub Desktop
       1. 打开 GitHub Desktop → File → Add local repository → 选 D:\hexo-blog
       2. 左侧 Changes 里勾选要提交的文件
          （不要勾 node_modules/、public/、多余副本文件）
       3. 底部输入 Summary（如"初始化Hexo博客"）
       4. 点 Commit to main
       5. 点顶部的 Push origin

⚠️ 只 Commit 不 Push = 代码只在本地，云端不会更新！


================================================================================
七、Cloudflare Pages 部署
================================================================================

1. 登录 dash.cloudflare.com
2. Workers 和 Pages → 创建应用程序 → 选 Pages（不是 Worker！）
3. 连接到 Git → 选 hexo-blog 仓库
4. 构建设置：
   - 项目名称：hexo-blog
   - 生产分支：main
   - 框架预设：无
   - 构建命令：npx hexo generate
   - 输出目录：public
   - 根目录：留空
   - 环境变量：NODE_VERSION = 24
5. 保存并部署 → 等变绿 ✅

部署日志正常应该包含：
   - Installing dependencies...
   - Running build command...
   - Generated:（后面列出生成的文章）
   - Uploading...
   - Success!


================================================================================
八、GoDaddy 改 NS（接入 Cloudflare）
================================================================================

1. Cloudflare 添加站点 readhaven567.top → 拿到两个 NS 地址
2. 去 GoDaddy → 域名 → DNS → Nameservers → Change
3. 删掉原来的 ns63/ns64.domaincontrol.com
4. 填 Cloudflare 给的两个 NS → Save
5. 关闭 DNSSEC（重要！否则证书可能签发失败）
6. 等状态从 Pending 变 Active（几分钟到 24 小时）


================================================================================
九、绑定自定义域名
================================================================================

1. Pages 项目 → 自定义域 → 设置域
2. 输入 readhaven567.top → 确认
3. Cloudflare 自动添加 DNS 记录
4. 等证书签发完，状态变 Active
5. 访问 https://readhaven567.top

SSL 设置：
   左侧 SSL/TLS → 加密模式选 完全（Full）→ 开「始终使用 HTTPS」


================================================================================
十、修改 Hexo 的 url 配置
================================================================================

编辑 D:\hexo-blog\_config.yml：
       url: https://readhaven567.top
       root: /

然后重新生成并推送：
       hexo clean && hexo generate
       git add . && git commit -m "绑定正式域名" && git push

十二、常见报错排查
================================================================================

问题                        原因                        解决
--------------------------------------------------------------------------------
js-yaml 报错 / Cannot GET/  文章 Front-matter 格式错误  检查 title: 后是否有空格
                                                       检查 --- 是否完整
部署红色失败                构建命令没填或 Node 版本    检查 npx hexo generate
                           不对                       和 NODE_VERSION=24
.pages.dev 能开域名打不开   NS 没生效或自定义域没绑    等 NS 传播 / Pages 里绑

                            Pages

手机能开电脑不能            电脑 DNS 缓存旧了           ipconfig /flushdns
推送后网页没更新            浏览器/CDN 缓存              Ctrl + F5 强刷
                                                       / Cloudflare 清缓存
本地 hexo s 看不到新文章    文章格式错误或文件放错       检查 Front-matter
                           位置                        / 确认在 _posts 里
GitHub Desktop 显示 0       文件已提交或未检测到变化    点 Ctrl+R 刷新
changed files                                          检查文件是否在正确目录

十六、本次实战踩坑记录
================================================================================

1. ❌ 文件名带 .md.md 双后缀
   ✅ 只用 hexo new "标题" 不加 .md

2. ❌ 文章没写 Front-matter
   ✅ 顶部加 --- + title: + date:

3. ❌ 文件夹里有"副本.md"
   ✅ 删掉，避免重复渲染

4. ❌ 域名绑到 Worker 导致 ERR_CONNECTION_CLOSED
   ✅ 解绑 Worker，在 Pages 绑

5. ❌ SSL 用 Flexible 导致重定向循环
   ✅ 改 Full

6. ❌ GitHub Desktop 只 Commit 没 Push
   ✅ 必须点 Push origin

7. ❌ DNSSEC 没关
   ✅ GoDaddy 关闭 DNSSEC
