## 一、工作原理：扫描到邮件到底发生了什么

### 1.1 一句话说清本质

> 复印机扫描到邮件，本质上就是：**复印机充当一台"邮件客户端"，把扫描好的 PDF 文件当作附件，通过 SMTP 协议发送到指定邮箱。**

这和你在电脑上用 Outlook 发一封带附件的邮件，原理完全一样——只不过"写信的人"换成了复印机。

### 1.2 完整数据流程图

```
┌─────────────┐    ①扫描成像     ┌──────────────┐    ②生成PDF      ┌──────────────┐
│  纸质原稿    │ ──────────────→ │  复印机内部   │ ──────────────→ │  PDF/图像文件  │
└─────────────┘                  │  扫描组件     │                 └──────┬───────┘
                                 └──────────────┘                        │
                                                                        ↓
┌─────────────┐    ⑥邮件送达     ┌──────────────┐    ③SMTP提交     ┌──────────────┐
│  收件人邮箱  │ ←────────────── │  企业微信     │ ←────────────── │  复印机       │
│  (收件箱)   │                  │  邮件服务器   │    SMTP协议      │  (SMTP客户端) │
└─────────────┘                  │              │    SSL/TLS加密   └──────────────┘
                                 └──────┬───────┘
                                        ↑
                                  ④验证身份
                                  ⑤接收邮件
```

**逐步拆解：**

| 步骤 | 发生了什么 | 对应配置项 |
|------|-----------|-----------|
| ① 扫描成像 | 复印机光学组件扫描原稿，生成数字图像 | 面板扫描参数（分辨率、颜色） |
| ② 生成文件 | 复印机将图像编码为 PDF（或多页 TIFF） | E-Mail 设置中的"文件格式" |
| ③ SMTP 提交 | 复印机作为 SMTP 客户端，通过 SSL/TLS 加密通道连接邮件服务器 | SMTP 服务器地址 + 端口 465 + SSL/TLS |
| ④ 验证身份 | 服务器要求登录认证，复印机发送"登录名 + 授权码" | 验证方式 Login + 登录名 + 密码（授权码） |
| ⑤ 接收邮件 | 服务器接收邮件，转发到收件人邮箱 | 收件人地址（地址簿） |
| ⑥ 邮件送达 | 收件人在企业微信邮箱中收到带附件的邮件 | — |

### 1.3 为什么必须用"授权码"而不是登录密码？

这是整个配置中最容易困惑的点，原理如下：

```
传统方式（已废弃）：
  客户端 ──输入网页密码──→ 邮件服务器 → 通过

企业微信安全机制（当前）：
  客户端 ──输入专用授权码──→ 邮件服务器 → 通过
                                ↑
                    授权码由服务器单独生成
                    与网页密码完全独立
                    可随时单独吊销
```

**设计原因**：如果直接用网页登录密码，一旦复印机被入侵或密码泄露，攻击者不仅能发邮件，还能登录你的邮箱查看所有内容。授权码机制实现了**权限隔离**——即使授权码泄露，攻击者只能发邮件，无法登录邮箱读取邮件。

### 1.4 为什么需要管理员开启 SMTP 权限？

```
企业微信管理后台
┌─────────────────────────────────────────┐
│  协作 → 邮件 → 安全管理 → 客户端访问限制   │
│                                         │
│  总开关：是否允许第三方客户端连接 SMTP     │
│     ├─ 允许名单：哪些成员可以用           │
│     └─ 禁止名单：哪些成员被拦截           │
└─────────────────────────────────────────┘
         ↓ 总开关关闭时
  复印机 → SMTP 连接请求 → 服务器拒绝（无论密码对错）
```

**原理**：企业微信默认禁止所有第三方客户端连接，这是安全策略。管理员需要显式"放行"指定成员，服务器才会接受来自复印机的 SMTP 连接请求。这一步是**服务端策略**，不是复印机端的设置。

### 1.5 SSL/TLS 加密的作用

```
无加密（不安全）：
  复印机 ──明文传输──→ 服务器
  （授权码、邮件内容在网络上裸奔，可被窃听）

SSL/TLS 加密（安全）：
  复印机 ══加密隧道══→ 服务器
  （授权码和邮件内容全程加密，即使被截获也无法解密）
```

- **端口 465 + "通过 SSL/TLS"**：连接建立时立即加密（隐式 SSL）
- **端口 587 + "STARTTLS"**：先建立明文连接，再升级为加密（显式 TLS）

两种方式的加密强度相同，区别仅在于协商时机。企业微信邮箱两种都支持。

### 1.6 为什么"接收人域名"只填域名部分？

```
复印机拼接逻辑：

  用户名（地址簿中填写） + @ + 接收人域名（E-Mail设置中填写）
  
  例：地址簿填 "zhangsan" + @ + 域名填 "gzfei.com"
      → 最终邮箱：zhangsan@gzfei.com

  如果域名填了完整邮箱 "wushukun@gzfei.com"：
      → 拼接结果：zhangsan@wushukun@gzfei.com  ← 非法地址！
```

这是东芝复印机的设计逻辑：将"用户名"和"域名"分开存储，发送时自动拼接。如果域名栏填了完整邮箱，会导致双重 `@` 符号，形成非法邮箱地址。

## 二、整体配置流程概览

```
① 管理员开启 SMTP 权限（企业微信后台）
        ↓
② 生成客户端专用授权码（邮箱网页端）
        ↓
③ 复印机网络基础配置（DNS + 时间校准）
        ↓
④ SMTP 客户端参数配置（服务器/端口/加密/认证）
        ↓
⑤ E-Mail 常规设置 + 地址簿添加收件人
        ↓
⑥ 连接测试 → 保存 → 重启 → 面板扫描发送
```

**依赖关系说明**：
- 步骤 ① 是 ② 的前提（不开权限，网页端"开启 IMAP/SMTP"开关是灰色的）
- 步骤 ③ 是 ④ 的前提（DNS 不通则无法连接服务器，时间不对则 SSL 证书验证失败）
- 步骤 ④ 是 ⑤⑥ 的前提（SMTP 不通，后面的设置毫无意义）
- 步骤 ⑤ 和 ⑥ 可以合并操作

## 三、企业微信后台开启 SMTP 权限

> **必须由企业微信超级管理员操作**

### 操作步骤

1. 电脑浏览器打开企业微信管理后台：https://work.weixin.qq.com
2. 用**企业创建人 / 超级管理员**账号登录
3. 左侧导航进入：**协作 → 邮件 → 安全管理**
4. 点击 **客户端访问限制**
5. 找到 **修改 POP/SMTP 服务范围**（部分版本显示为"修改 Exchange/IMAP/SMTP 服务范围"）
6. 将发件人账号（如 `wushukun@gzfei.com`）勾选加入允许名单
7. 点击确定保存

### ⚠️ 注意事项

- 如果没有做这一步，网页邮箱端的"开启 IMAP/SMTP 服务"开关会是**灰色不可点击**状态
- 普通成员无权限操作此步骤，必须联系 IT 管理员
- 部分企业微信版本路径可能略有不同，可尝试"协作 → 设置 → 第三方客户端"

## 四、生成客户端专用授权码

> **由发件人本人操作**

### 操作步骤

1. 电脑浏览器登录企业邮箱网页版：https://exmail.qq.com 或 https://work.exmail.qq.com
2. 进入 **设置 → 邮箱绑定**
3. 开启 **安全登录**
4. 点击 **生成新密码**（客户端专用密码 / 授权码）
5. 验证身份后，系统生成一串 **16 位授权码**（只显示一次）
6. **立即复制保存**

### ⚠️ 关键提醒

- **绝对不能用网页登录密码**作为 SMTP 密码
- 授权码与账号绑定：A 账号生成的授权码不能在 B 账号上使用
- 如果更换了发件人账号，必须重新登录新账号生成新的授权码

## 五、复印机网络基础配置

### 5.1 DNS 设置

**路径**：TopAccess → [Setup] 设置 → [Network] 网络 → [TCP/IP]

| 参数 | 推荐值 |
|------|--------|
| 首选 DNS | `114.114.114.114` |
| 备用 DNS | `8.8.8.8`（可选） |

**原理说明**：SMTP 配置中填的是域名 `smtp.exmail.qq.com`，复印机需要通过 DNS 服务器将这个域名解析为 IP 地址（如 `163.177.72.xxx`）才能建立连接。没有 DNS 或 DNS 错误，会导致"连接超时"。

> 如果不配置 DNS，复印机无法通过域名找到邮件服务器，会导致连接超时。

### 5.2 系统时间与时区校准

**路径**：TopAccess → [Setup] 设置 → [General] 常规 → Date & Time

| 参数 | 推荐值 |
|------|--------|
| 时区 | `GMT+08:00`（北京/重庆/香港/乌鲁木齐） |
| 日期 | 当前实际日期 |
| 时间 | 当前实际时间 |

**原理说明**：SSL/TLS 证书有有效期（起始日期和过期日期）。如果复印机系统时间与实际偏差过大（比如年份不对），证书会被判定为"尚未生效"或"已过期"，导致 SSL 握手失败，连接被断开。

> 如果系统时间与实际偏差过大，SSL 证书验证会直接失败，导致连接被断开。修改时间后需重启设备生效。

## 六、SMTP 客户端参数配置

**路径**：TopAccess → [管理] → [设置] → [E-Mail] → SMTP 客户端 / POP3 客户端 → 设置

### 完整参数对照表

| 参数项 | 推荐值 | 原理说明 |
|--------|--------|----------|
| SMTP 服务器地址 | `smtp.exmail.qq.com` | 腾讯企业邮 SMTP 服务器域名 |
| 端口号 | `465` | SSL 隐式加密端口（备用：587） |
| SSL/TLS | `通过 SSL/TLS` | 建立连接即加密（对应 465 端口） |
| 验证方式 | `Login` | 使用 SMTP AUTH 认证（必须选 Login） |
| 登录名 | `wushukun@gzfei.com` | 完整邮箱地址，作为 SMTP 认证用户名 |
| 密码 | 16 位授权码 | 第三步生成的授权码，不是网页密码 |
| 启用 SSL/TLS | `接受所有无 CA 的证书` | 兼容自签名证书，避免验证失败 |
| SMTP 之前 POP | `禁止` | 不需要先通过 POP 认证 |
| 启动 SMTP 客户端 | `启动` | 必须启用，否则无法发送 |

### 备用方案（如果 465 端口不通）

| 参数项 | 备用值 |
|--------|--------|
| 端口号 | `587` |
| SSL/TLS | `STARTTLS` |

**原理说明**：部分企业防火墙只开放 587 端口，不开放 465 端口。STARTTLS 的工作方式是：先建立明文 TCP 连接，然后客户端发送 `STARTTLS` 命令，双方协商后升级为加密连接。安全性与 465 端口相同。

### 测试与保存

1. 填完所有参数后，点击 **[连接测试] → [执行]**
2. 如果提示"连接成功"，点击 **[确定]**
3. **必须点击**页面左上角的 **[保存]** 按钮
4. 建议重启复印机使配置彻底生效

## 七、E-Mail 常规设置

**路径**：TopAccess → [管理] → [设置] → [E-Mail] → 常规设置

### 关键参数

| 参数项 | 推荐值 | ⚠️ 易错点 |
|--------|--------|-----------|
| 发件人地址 | `wushukun@gzfei.com` | 必须与 SMTP 登录名一致 |
| 发件人姓名 | `wushukun` | 不要填数字或特殊字符 |
| 接收人域名 | `gzfei.com` | **只填 @ 后的域名，不填完整邮箱！** |
| 文件格式 | `PDF (多页)` | 黑白/彩色均可 |
| 主题编辑 | `禁止` | 避免面板输入问题 |
| 缺省主题 | 出厂设置 | — |
| 重试次数 | 3 次 | — |
| 重试间隔 | 1 分钟 | — |

### ⚠️ "接收人域名"常见错误

- ❌ 错误：`wushukun@gzfei.com`（填了完整邮箱）
- ✅ 正确：`gzfei.com`（只填域名部分）

**原理**：如第一章 1.6 节所述，复印机会将地址簿中的用户名与接收人域名自动拼接。填错会导致双重 `@` 符号，形成非法邮箱地址，触发错误代码 **2C6B**。

## 八、添加收件人（地址簿）

> 收件人需要添加到地址簿后，才能在面板端选择发送

### 方法一：网页端添加（推荐，适合批量）

1. TopAccess 顶部点击 **[登记]** 标签
2. 点击 **[地址簿]**
3. 点击 **[添加地址]**
4. 填写：
   - 姓名（如"财务部"）
   - 电子邮件（目标收件人邮箱，如另一个企业微信邮箱）
   - 用途：勾选"用于扫描发送"
5. 点击保存

### 方法二：面板端添加

1. 面板点击 **[扫描] → [地址簿]**
2. 选中一个空白行 → 点击 **[登录/输入]**
3. 输入姓名和目标邮箱地址
4. 点击 **[确定]**

---

## 九、面板端发送操作

1. 在复印机面板放好原稿
2. 点击 **[扫描]** 功能
3. 打开 **[地址簿]**，选中已添加的收件人
4. 确认扫描参数（分辨率、颜色、文件格式）
5. 点击 **[发送]**
6. 等待面板显示"发送完成"

## 十、常见问题与错误代码速查

### 错误代码对照表

| 错误代码 | 含义 | 根因分析 | 解决方案 |
|----------|------|----------|----------|
| `2C64` | 未设置终端邮件地址 | 复印机没有"发件人地址"，SMTP 认证时无身份 | 在 E-Mail 常规设置中填写"发件人地址"，保存并重启 |
| `2C6B` | 终端邮件地址错误 | "接收人域名"误填了完整邮箱，导致拼接出非法地址 | 检查"接收人域名"是否误填了完整邮箱（应只填域名） |
| `2C69` | 无法连接 SMTP 服务器 | DNS 未配/时间不对/防火墙封端口/服务器地址错 | 依次排查 DNS → 系统时间 → 防火墙端口 → 服务器地址 |
| `2C71` | SMTP 认证失败 | 授权码错误/授权码与账号不匹配/未开启 SMTP 权限 | 检查授权码是否正确、是否与发件人账号匹配 |
| `2A60` | 扫描用户验证失败 | 面板开启了用户认证，操作员账号未绑定邮箱 | 关闭用户认证，或在用户管理中绑定邮箱 |

### 其他常见问题

**Q：网页端连接测试成功，但面板发送提示"发件人地址未登陆"？**

可能原因（按概率排序）：
1. 配置修改后未点击 [保存]，设备重启后配置丢失
2. 面板开启了"用户认证"，操作员工账号未绑定邮箱
3. 地址簿中没有添加收件人

**Q：提示连接超时？**

排查方向（按概率排序）：
1. DNS 未配置或配置错误
2. 系统时间/时区不正确
3. 公司防火墙封了 465 端口（尝试改用 587 + STARTTLS）
4. 网络线路本身不通

**Q：邮件发出去了但收不到？**

排查方向：
1. 检查垃圾邮件箱
2. 确认"发件人姓名"不是数字或特殊字符（可能被反垃圾邮件拦截）
3. 确认收件人邮箱地址拼写正确
